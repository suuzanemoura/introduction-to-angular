# Introdução ao Angular

## Descrição
Este projeto é uma aplicação web simples desenvolvida como parte dos estudos do Santander Bootcamp 2023: FullStack Java + Angular. Ele tem como objetivo introduzir os principais conceitos e funcionalidades do framework Angular.

## Link de Acesso

- Deploy no stackbliz: [Clique aqui!](https://introductiontoangular.stackblitz.io)

## Sobre o Projeto

### Tecnologias
- HTML5
- CSS3
- JavaScript
- Angular
- BootStrap

### Destaques do Projeto
- Estrutura básica com Angular CLI;
- Uso de componentes reutilizáveis;
- Estilização com Bootstrap;
- Deploy rápido com StackBlitz.

### Status do projeto

- ✅ Concluído
